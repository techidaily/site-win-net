To run the software you’ll need a Kinect camera (_without the XBox_) with a USB adapter, and a PC (or Mac running Windows on Parallels 10). If you have the hardware, download the free trial at [visikord.com/product](http://visikord.com/product) and give it a go. Or run the Trial in the demo mode if you don’t have a Kinect but want to see the visuals in action right away!

The **Visikord Advanced** edition includes the game and the freestyle dance mode, along with custom jpeg and movie backgrounds, logos, photobooth and other goodies. Please see [Visikord.com](http://visikord.com) for sample videos, screenshots and specs. **_Thank you!_**
